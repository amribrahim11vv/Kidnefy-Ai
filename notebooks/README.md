# Notebooks Directory

This directory is reserved for **Jupyter Notebooks** (`.ipynb`) used for:
-   Data Analysis & Visualization (EDA)
-   Model Experimentation
-   Prototyping new features

## Best Practices
-   Keep exploratory code here, but move production-ready code to `src/`.
-   Name notebooks clearly (e.g., `01_data_exploration.ipynb`, `02_model_training_experiment.ipynb`).
